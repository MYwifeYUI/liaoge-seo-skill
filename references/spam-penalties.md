# SEO 作弊及惩罚（第10章精华）

> 本章目的不是教读者作弊，而是：了解黑帽手法避免无意误用、识别风险、被陷害时有诊断起点。ZAC 的立场：做白帽，承担风险就不要抱怨。

## 目录
1. 白帽、黑帽、灰帽
2. 主要作弊方法清单

## 1. 白帽、黑帽、灰帽

- 黑帽 = 不符合搜索引擎质量规范的手法；灰帽 = 介于两者之间。本质是**风险度判断**。
- 道德与法律底线：黑客入侵、非法采集抄袭是违法犯罪，绝不能碰；SEO 服务商必须事前告知客户黑帽风险，由客户判断。
- 黑帽的贡献：测试搜索引擎底线，让行业知道哪些手法被接受；但被惩罚是必然的，做了就别抱怨。
- **不要学大网站**：权重高的网站和成名网站能做的，小网站不一定能做（搜索引擎为自身用户体验对大站更容忍）；盲目跟风很危险。
- **不要存侥幸心理**：搜索引擎的目标是控制垃圾比例，今天没惩罚不代表以后不惩罚。

## 2. 主要作弊方法清单（识别与规避）

- **隐藏文字（Hidden Text）**：与背景同色/相近色文字、隐藏 div 等；被发现的惩罚风险极高。
- **隐藏链接（Hidden Links）**：用户看不到的链接（黑入网站注入最常见）；搜索引擎倾向使隐藏链接效果归零。
- **垃圾链接（Link Spam）**：在任何可留言处留下目标关键词锚文字链接。识别特征：留言含链接数量、垃圾关键词、指向黑名单网站、同一时间段大量出现在多个博客、留言与主题无关、群发速度。效果非常值得怀疑（排名靠前可能靠的是少量高质量链接）；搜索引擎通常直接忽略。
- **买卖链接（Paid Links）**：百度绿萝算法打击买卖双方及中介；Google 曾自降日本站 PR。检测线索：内容不相关、链接突然出现/消失、出现在页脚/赞助商位置、使用链接交易服务、与已知买卖网站关联。规避误判（即使是商业合作）：广告链接加 nofollow/sponsored、来源和锚文字多样化、匀速增加、避免页脚、尽量找不常卖广告的网站。
- **链接农场（Link Farm）**：纯为交换链接存在的页面/网站，常共用软件（页面格式相同易识别）；搜索引擎会忽略或惩罚其链接。
- **坏邻居（Bad Neighborhood）**：链接到被惩罚/作弊网站可能连累自己；交换链接前判断对方是否作弊/被罚。别人链接到你（坏邻居）你控制不了，但你链接到别人要负责。
- **隐藏页面（Cloaking）**：对蜘蛛返回优化版、对用户返回正常版；与 IP 传送的区别：同一 IP 的蜘蛛和用户看到的内容是否一致。判断方法：伪装 UA、看快照差异。
- **PR 劫持**：用 301/302 转向借高 PR 页面的权重；判断：看 Google 快照与真实页面是否不同。
- **桥页（Doorway）**：软件生成的充满关键词、无意义的页面，跳转或引导到推广站。
- **跳转**：除 301 外都可疑；万不得已用跳转也应在 10 秒以后。
- **诱饵替换（Bait and Switch）**：先用普通词做排名，再换成商业/非法内容。
- **关键词堆积（Keyword Stuffing）**：标题/描述/页脚堆关键词，甚至无关热门词（如卖童装加"周杰伦、iPhone"——会被判作弊连本来内容都无法排名）。
- **大规模站群**：大量低质量网站共同推广主站；链轮等互相链接形式辨别无压力；隐藏（不同公司/IP/注册信息/模板、无交叉链接）很难完全做到；数量大、质量低就是作弊。
- **利用高权重网站**：维基、免费博客、大学/政府子域、寄生虫程序（黑入上传自动生成页面）、租借目录/子域名、利用高权重站搜索生成 URL。注意：部分方法违法犯罪；了解它是为了诊断自己网站被黑。
- **采集和伪原创**：去重算法对页面正文算数字指纹（MD5 类）；加"的的的"、调换段落顺序、混排不同文章都不能改变指纹；简单伪原创骗不过搜索引擎。
- **百度点击器及快排**：模拟点击/发包（破解结果页 URL 参数后直接访问）；"惊雷算法"打击，但未完全解决；有作用但有被惩罚封禁风险，可能追溯既往；白帽借鉴其原理：做好用户体验、降低跳出率、写好标题。
- **镜像网站**：实时抓取别人网站内容（小偷程序）；被恶意镜像的根本解决办法：屏蔽对方抓取 IP。
- **刷各种数据**：刷 Alexa、相关搜索、百度指数、搜索框建议（原理都是构造特定 URL 增加访问量）；对真实流量无作用，主要骗外行。
- **负面 SEO（Negative SEO）**：给对手制造大量垃圾链接/垃圾页面/桥页/采集镜像，试图让搜索引擎惩罚对手；现实中可能实现但极为罕见；**最好的防御是提高自己网站的质量和权重**（负面 SEO 案例都发生在本身权重低、链接弱的网站）；怀疑被陷害时做全面安全检查 + 监控外链异常飙升。

## 3. 搜索引擎惩罚机制

- **积分制**：每出现一个涉嫌作弊的地方加积分，达到门槛才惩罚；门槛是滑动的（大站容忍度高、小站门槛低）。
- 单一作弊手法（轻度关键词堆积、偶尔一个坏邻居链接）可被解释为疏忽；多种手法叠加（堆积+垃圾链接+买卖链接+站群+敏感热门词）就是系统性作弊。
- 经典案例（英国家具站）：Matt Cutts 点出"不自然的链接建设"（赞助模板版权链接）+ 论坛垃圾内容 + 付费博客帖子 + 无关主题评论——单独出现没事，叠加起来就是惩罚。
- 惩罚种类：整站删除（robots 问题/服务器问题/违法内容投诉）、主要关键词排名下降（锚文字过度集中或垃圾链接导致）、所有关键词大幅下降（前几十页到几百页后）。
- 检测：site: 指令查收录、排名异常；区分"被惩罚"与"算法更新/竞争加剧"（小幅下降一般不是惩罚）。

## 4. 被惩罚了怎么办

- **知道原因**：清理作弊元素（垃圾链接、隐藏文字、买卖链接、垃圾页面），通过百度资源平台反馈 / GSC 拒绝外链，然后等待重新评估。
- **不知道原因**：全面检查——外链是否被陷害、网站是否被黑（注入隐藏内容/恶意转向/寄生虫）、是否误用 nofollow/noindex/robots、内容是否有采集抄袭；检查日志、服务器头信息（404 是否返回 200）。
- 调整期望：恢复需要时间；大站名站被删能快速恢复是因为有特殊沟通渠道，普通站长要做好长期准备。
