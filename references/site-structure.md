# 网站结构优化（第4章精华）

> 网站结构是 SEO 的基础，比页面优化更重要。诊断网站时按本文件逐项检查。

## 1. 从蜘蛛角度看网站（三个问题）

1. **能不能找到网页**：所有页面通过可爬行的普通 HTML 链接可达；与首页点击距离控制在 4-5 次点击以内。
2. **找到后能不能抓取**：URL 参数过多、Session ID、整页 Flash、框架、可疑转向、大量复制内容都会让蜘蛛敬而远之。
3. **抓取后能不能提炼信息**：关键词在重要位置、重要标签、代码精简、兼容性。
- 一句话：**良好引用，良好结构，良好导航**。

## 2. 蜘蛛陷阱（必须避免）

- **Flash**：整个首页是大 Flash 就等于没有文字内容；2017 年起搜索引擎已忽略 Flash。
- **Session ID**：加在 URL 中导致同一页面无数 URL、复制内容；用 Cookies 跟踪用户，或对蜘蛛不生成 Session ID。
- **各种跳转**：除 301 外（302、JS、Meta Refresh）都让搜索引擎敏感；能不用就不用。
- **框架结构**（Frame）：不研究、不使用；后台/控制面板可以用。
- **动态 URL 参数过多**：一般 2-3 个参数以内没问题；几十个参数强烈不建议。
- **JavaScript 链接**：导航必须用标准 `<a>` 标签；Google 可能执行 JS（分步渲染，低权重站可能不执行），百度基本不执行——**中文站尤其不能用 JS 生成导航或调用可见内容**。
- **要求登录/强制 Cookies**：会员区内容蜘蛛看不到；蜘蛛相当于禁用 Cookies 的浏览器。

## 3. 物理结构与链接结构

- **物理结构**：扁平式（适合小站，所有页面在根目录）或树形（分类目录 + 产品页）。深层物理目录不影响收录——**收录与否取决于链接结构中的位置，不是物理深度**。
- **链接结构（更重要）**：标准树形——
  - 首页链接所有分类首页；
  - 首页一般不直接链接产品页（重点推广的产品除外）；
  - 分类首页互链（以导航形式）、都链回首页、链接本分类产品页；
  - 产品页链回首页和所有分类首页（导航）、可链接同分类其他产品页。
- 权重均匀分布：深层内页通过 4-5 次点击可达，是树形结构的目标。

## 4. 清晰导航

- 用最普通的 HTML 文字导航（不用图片、不用 JS）；导航是收录最重要的内部链接。
- 页面与首页点击距离越近越好；主导航中的页面处于仅次于首页的层次。
- 分类名称尽量用目标关键词（2-4 字为宜），顾及用户体验，不堆积。
- **强烈建议面包屑导航**。
- 避免页脚堆砌关键词链接（近年搜索引擎反感）。

## 5. 子域名还是目录

- 大部分情况下**用目录**：子域名 = 独立网站，权重分散，外链建设要两遍。
- 例外：内容足够独立成站（门户级频道）、多语言/国家站、百度优化（百度给首页权重高，子域名/独立域名更有利）。
- 英文站（Google 目标）用目录结构；Google 对首页/目录/内页权重大致相同。

## 6. robots、noindex、nofollow

- **robots 文件**：禁止抓取（不禁止索引）；被禁止的 URL 有导入链接仍可能以"只有 URL"或锚文字形式出现在结果中（例：淘宝整站禁止百度抓取，百度仍返回首页信息）。
- **noindex**：禁止索引（需先被抓取）；`noindex, nofollow`、`nosnippet`、`noarchive` 等可组合；百度目前官方只支持 nofollow 和 noarchive。
- 想让 URL 完全不出现在结果中：robots 禁止抓取 + noindex（注意 noindex 必须能被抓取到才能生效）。
- **nofollow**：告诉蜘蛛不要爬行该链接、不传权重（不禁止抓取和索引）。
  - Google 2008 年起 nofollow 链接权重"凭空消失"（不转移给其他链接）——**英文站用 nofollow 会浪费权重**，Google 官方不建议用 nofollow 控制内链权重。
  - 百度把 nofollow 视为链接不存在，不传权重也不浪费——**中文站可给无必要页面加 nofollow**。
  - 2019 年 9 月起 Google 将 nofollow / rel="sponsored" / rel="ugc" 视为"建议 hint"而非指令；Bing 一直如此。
  - 适用场景：评论区/论坛链接、广告链接、不想被收录且数量大的页面（排序/筛选页）、抓取量过大的无价值页面。
- 页面没收录先查原始日志：被抓过 → 大概率内容质量问题；没被抓 → 网站结构问题。

## 7. URL 设计

- **短 URL 点击率高**（搜索结果实验：短 URL 在长 URL 下方时点击率高 2.5 倍）、利于传播。
- 尽量静态化（即使 Google 说能抓动态 URL：还要考虑百度/Bing、用户体验、参数乱序导致的复制内容）；动态 URL 参数 ≤ 2-3 个。
- 目录层次尽量少；英文站目录/文件名有描述性，关键词进 URL 略有帮助但别堆积；中文站 URL 不建议放中文字符。
- 单词间用**短横线 `-`**（搜索引擎当空格），不用下划线 `_`（被忽略）。
- 全站用 **https**（是排名因素之一，虽小；百度已完全支持 https）。
- 目录形式 vs 文件形式对排名无大影响。

## 8. 网址规范化（Canonicalization）

- 问题：同一内容多个 URL（www/非 www、http/https、index.html、参数顺序），分散权重、复制内容、收录浪费；网上估计 10%-30% 的 URL 是重复内容。
- 解决：
  1. 所有内部链接统一用规范化 URL；
  2. XML 网站地图只列规范化 URL；
  3. 301 转向（Google 传递大部分权重、需 1-3 个月；百度较保守，新旧 URL 会并存很久）；
  4. canonical 标签（2009 年 Google/Yahoo/微软发布，百度 2013 年起支持）——**是建议不是指令**，指定页面内容必须与规范化页完全相同或高度相似才有效。
- 原则：与其交给搜索引擎判断，不如自己做好规范化，不给它判断错误的机会。

## 9. 复制内容

- 搜索引擎**不会因少量复制内容惩罚网站**，只是从多个版本中挑原创/用户体验最好的版本排名；同站复制会分散权重、浪费收录机会。
- 产生原因：网址规范化问题、打印版本、排序/筛选/翻页版本、RSS 生成、Session ID、正文过短（通用部分占比高）、转载抄袭、按地区拆分的近似页面。
- 检查方法：取正文一句话加双引号搜索，看是否有多个页面包含。
- 解决：一篇文章只对应一个 URL；其他版本 robots 禁止抓取或 noindex；连向复制版本的链接加 nofollow；canonical 标签指向主版本。
- 跨站复制：加版权声明 + 保留原出处链接（原创的判定信号）；坚持原创；被大量抄袭可联系对方/投诉。

## 10. 绝对路径与相对路径

- 绝对路径利于：被抄袭时链接也指向你、RSS 转载、规范化（蜘蛛从非 www 版本也能回到 www）、页面移动后链接仍正确。
- 相对路径利于：移动内容方便。
- 正确解析的前提下，**两者对排名本身没有影响**；建议用绝对路径。

## 11. 网站地图

- **HTML 网站地图**：列出主要页面链接（一级/二级分类即可，或拆成多个）；是 JS 导航网站的收录补充。
- **XML 网站地图**：最多 5 万个 URL、不超过 50MB（百度 10MB）；只列规范化 URL；`changefreq`/`priority` 只是提示；超限用 sitemap index；通过站长工具提交或在 robots 中指定位置。

## 12. 内部链接与权重分配

- 有意识地规划页面重要程度：重点内页多给内部链接；非必要页面（隐私政策、登录页）少给或 nofollow（中文站）。
- 翻页过多的分页可考虑折叠/加载更多，避免权重分散；分类隔离避免跨分类产品页互链稀释。
- 内链锚文字多样化、自然；不要为了加内链而刻意加链接（内链总数过多的网站整体排名反而可能受影响）。
- 深层链接（Deep Link）：外链指向内页能让内页权重"释放"，很多一级分类页缺外链时权重明显偏低。

## 13. 404 页面与抓取份额

- 404 必须返回真正的 404 状态码（不能 200）；404 页面设计友好，给用户出路。
- 删除页面：返回 404，搜索引擎会逐渐清除。
- 大型网站抓取份额有限：把抓取资源留给有意义的页面，用 robots/nofollow 控制无意义页面（筛选、排序、翻页、参数组合页）。
- 监控：GSC 的抓取统计、日志中的蜘蛛访问、页面收录率（见 monitoring.md）。
